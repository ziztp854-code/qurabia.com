# معاينة القرى المهجورة المحلية

هذه معاينة مستقلة؛ لا يستدعيها مسار التطبيق العام، ولا تتصل بحسابات أو قاعدة بيانات الإنتاج. تشغيلها من `apps/web`:

```powershell
$env:ABANDONED_VILLAGE_PREVIEW='1'
node --import tsx e2e/fixtures/abandoned-village-server.ts
```

الرابط المحلي: `http://127.0.0.1:3348/`. تستمع إلى loopback فقط، ولا تقرأ ملفات البيئة. العالم الأول يضم لاعبي اختبار Alice وBob، والثاني Bob فقط. الجلسات هنا اصطناعية ومحصورة في خادم المعاينة، ولا تمثل تسجيل دخول المستخدم الحقيقي.

## قواعد التجربة

- 48 قرية لكل عالم، 12 في مصر و12 في الشام و12 في العراق و12 في الجزيرة العربية.
- الموارد العادية: الخشب والحجر والحديد والغذاء والذهب؛ لا عملات مدفوعة.
- البداية والسقف 3000 لكل مورد، والتجدد 100 لكل مورد في الساعة، مع حفظ الكسور وإيقاف التجدد عند نهاية الموسم.
- المخزون مشترك. حمولة الجيش الإجمالية توزع نسبيًا على المخزون المتاح، مع توزيع الباقي الصحيح بترتيب الموارد الثابت. المثال: حمولة 400 مع تساوي المخزون = 80 من كل مورد.
- الخصم عند الوصول، والإيداع عند العودة وفق سعة مخزن قرية اللاعب. لا حامية ولا احتلال للقرى المهجورة.
- إحداثيات اللعبة الشبكية وقواعد سرعة الوحدات والقادة الحالية تحدد مدة السفر. الإحداثيات الجغرافية للعرض وتحديد اليابسة فقط.
- المواقع محفوظة ضمن JSON العالم. قراءات العالم لا تعيد توليدها، وإعادة التهيئة لعالم يحمل سجلًا محفوظًا تعيد السجل نفسه حتى لو تغيرت البذرة أو القناع.
- الإنشاء محصور في معرفات `preview_abandoned_*`. المستودع يتحقق من المعرف والسجل داخل قفل العالم، ويرفض الأمر الجديد في العوالم الأخرى. إنشاء العوالم العادي لا يضيف قرى مهجورة.

## المجال الجغرافي للمراجعة

قناع Natural Earth 10m، مع استبعاد البحيرات و5 كم على الأقل من حدود اليابسة، وفصل 20 كم بين المواقع و2 كم عن مواقع اللاعبين المقدمة للمولد. تشمل أقنعة البلدان: EGY، SYR، LBN، JOR، ISR، PSX، IRQ، SAU، YEM، OMN، ARE، KWT، QAT، BHR. لا تشمل هذه التجربة تركيا أو إيران أو قبرص. هذا اختيار معاينة قابل للتعديل قبل اعتماد النشر، ولم يطبق على أي عالم حقيقي.

المصدر والـSHA-256 محفوظان في `abandoned-middle-east-geography.json`. بيانات المصدر الأصلية وحقوق الاستخدام: [Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/). تجهيز القناع صريح وغير متصل بالشبكة:

```powershell
node tools/mamluk/prepare-abandoned-preview-geography.mjs <مجلد-الملفات-المصدرية> apps/web/e2e/fixtures/abandoned-middle-east-geography.json
```

الخريطة في المعاينة تعرض القناع الإقليمي المقصوص، دون طبقات تضاريس أو بيانات اللاعب من الموقع العام. القرى لها مصدر MapLibre منفصل عن قرى اللاعبين والمعالم العامة. لوحة الاختيار تدعم القائمة والفأرة واللمس ولوحة المفاتيح.

## الفحوص

```powershell
# من apps/web؛ عامل واحد
node node_modules/vitest/vitest.mjs run src/lib/kingdoms/abandoned-villages.test.ts src/lib/kingdoms/abandoned-preview-store.test.ts src/lib/kingdoms/resource-sites.test.ts src/lib/kingdoms/commanders.test.ts --maxWorkers=1
node node_modules/@playwright/test/cli.js test --config playwright.abandoned-preview.config.ts --workers=1
```

اختبارات PostgreSQL لا تعمل إلا مع `KINGDOMS_TEST_DATABASE_URL` صريح يشير إلى loopback وقاعدة اسمها `kingdoms_test` أو `kingdoms_test_*`. لا تستخدم `DATABASE_URL` بديلًا. طبق المخطط على قاعدة جديدة قبل تشغيل `abandoned-repository.integration.test.ts`؛ لا حاجة إلى seed.

واجهات `/__preview_test/*` وأوامر إزاحة الوقت موجودة في خادم المعاينة فقط، ولا تضفها إلى التطبيق العام. لا تشغل build أو المتصفح بالتزامن مع مهمة القصر.
