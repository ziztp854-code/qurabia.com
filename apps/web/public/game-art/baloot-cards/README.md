# Baloot playing cards

32 local SVG faces for the Saudi Baloot deck (7, 8, 9, 10, J, Q, K, A).

Artwork: Adrian Kennard, classic SVG / print-ready playing cards, https://www.me.uk/cards/.
Source mirror: https://github.com/letele/playing-cards/tree/865a78eb940c1232e4b21523577c8fca52f694fe/assets
License: CC0 1.0 Universal. See LICENSE.txt (copied unchanged from the source).

Local presentation changes: blue/red/gold/ink/paper colors use a coordinated navy, crimson, gold and ivory palette. The ace of spades uses its plain central suit mark without the source QR code or printed website address. All other drawing paths, ranks and suits are retained.

No package or external runtime requests are required.
