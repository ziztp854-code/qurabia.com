# Android 0.3.0 — مراجعة التصميم

الإصدار 0.3.0، Android versionCode 5. يستند إلى إصلاح المصادقة وإغلاق بث المضيف، دون إعادة بناء المشروع أو تغيير خدمات الموقع.

## ما تغيّر

- خط Cairo المحلي والهوية الداكنة والذهبية نفسها، مع تدرّج أوضح للعناوين والنصوص وحالات التركيز.
- رأس دخول أصغر، حالة اتصال حقيقية في شارة، ونموذج أوضح مع بقاء كلمات المرور والجلسات ورسائل الأخطاء على مساراتها الأصلية.
- الرئيسية والغرف بتصنيفات أفقية وبطاقات تعرض بيانات الخادم. صور الغرف السبع تعيد استخدام ملفات WebP الأصلية للمشروع محليًا؛ الأغطية المخصصة تستمر عبر محلّل HTTPS الحالي.
- تنقل سفلي بأيقونات SVG موحدة باستخدام expo-image الموجود، دون إضافة حزم.
- حساب ومقاعد ودردشة أكثر وضوحًا، مع الحفاظ على إجراءات المضيف والمغادرة والإرسال والهدايا.
- نموذج الغرفة قابل للتمرير وزر الحفظ ثابت فوق مساحة لوحة المفاتيح.

## فصل التحقق الوظيفي عن العرض

Workflow `.github/workflows/android-auth-login.yml` يبني APK العام أولًا ويحفظ بصمته، ثم يشغّل اختبارات NextAuth وحفظ الجلسة وإنهاء غرفتين باستخدام خادم HTTPS وقاعدة PostgreSQL معزولين فعليًا. لا تُلتقط صور لحساب هذا الاختبار أو بيانات دخوله.

بعد إنهاء fixture وحذف مادته الخاصة، يغيّر CI ملف الدخول مؤقتًا لإنشاء APK معاينة منفصل **لا يُوزّع**. يعرض هذا الملف مكونات التطبيق الأصلية ببيانات عرض عامة ومعلّمة، دون AuthProvider أو جلسات أو اتصال صوتي أو كتابة إلى الخادم. كل إجراء كتابة يفشل صراحة. لا يدخل هذا الملف إلى APK الموزّع، وتُعاد مقارنة بصمة التسليم بعد الاختبارات ويُستعاد ملف الدخول الأصلي.

المعاينة تشمل الرئيسية والغرف والحساب والمجلس عند 320 و360 و427 و800dp، و360dp مع تكبير الخط مرتين، وحالتي لوحة المفاتيح للبحث والدردشة. يتحقق سكربت الالتقاط من المحاكي ووسم المعاينة وغياب حقول الدخول قبل كل صورة. لا يُحفظ XML أو سجل خام لشاشة تحمل حسابًا.

الصور تثبت عرض المكونات فقط. لا تثبت تسجيل الدخول أو خدمة الصوت أو أداء هاتف فعلي. نجاح التقاط الصور لا يساوي اعتماد جودة التصميم؛ تُراجع الصور المرئية الجديدة قبل الحكم. لا يُمنح تقييم رقمي لمعاينة ناقصة.

## الأدلة والبناء

- artifact `tahaddi-debug-RUN_ID-ATTEMPT`: APK العام المستقل دون Metro.
- artifact `android-reports-RUN_ID-ATTEMPT`: المصدر، نتائج الاختبارات، صور الدخول المجهول، ومعاينات العرض العامة وبيانات المقاس والخط.
- المصدر ثابت على SHA مسجل في التقارير؛ صور العرض موسومة بأنها fixtures عامة.
- نتائج التشغيل وروابط التنزيل والمراجعة الفعلية تسجّل في PR، مع حفظ حالات الفشل السابقة.

هذه نسخة Debug للاختبار. لا توجد مفاتيح إصدار إنتاج جديدة أو نشر أو دمج إلى main.
