# تحدي لايف

نسخة عربية RTL من الملفات المرفقة، بهوية تحدي: أسود وذهبي وسماوي، مع غرف صوتية مباشرة حتى أربعة مشاركين. الصفحة الرئيسية تعرض الغرف الفعلية؛ لا تعرض أعدادًا أو أصواتًا وهمية.

## التشغيل المحلي

```sh
npm ci
npm start
```

افتح `http://127.0.0.1:4178`. يستخدم التشغيل المحلي WebSocket، ويحافظ على الميزات الأصلية ورفع المقاطع محليًا. اختبار شخصين يحتاج سياقين منفصلين للمتصفح.

## Vercel

اختر مجلد هذا التطبيق كـRoot Directory، والإطار Other. أمر التثبيت `npm ci --ignore-scripts --workspaces=false` والبناء `npm run build` ومجلد الإخراج `public`.

الخادم المستضاف هو `api/live.mjs`: يستخدم HTTP polling لإشارات WebRTC والحضور والدردشة، مع حالة Redis مشتركة وقفل بمعرّف ملكية وحفظ ذري. الصوت ينتقل مباشرة بين المشاركين عبر WebRTC، وليس عبر طلبات polling. لا يعتمد التطبيق على ذاكرة مثيل Vercel أو قرصه المحلي. هذه بنية أولية صغيرة، بحد 100 اتصال و4 مشاركين في الغرفة؛ ليست SFU للبث الجماهيري.

متغيرات الخادم المطلوبة:

- `KV_REST_API_URL` و`KV_REST_API_TOKEN`: اتصال Upstash الموجود في Vercel. تظل البيانات تحت بادئة `tahaddi-live:v1:` بعيدًا عن مفاتيح تطبيقات أخرى.
- `LIVE_SESSION_SECRET`: سر مستقل لتوقيع جلسات الضيوف. عند نشر معاينة داخل مشروع تحدي يمكن استخدام `AUTH_SECRET` الموجود، مع فصل التوقيع باسم التطبيق.
- `TURN_URL` و`TURN_USERNAME` و`TURN_CREDENTIAL`: خادم ترحيل اختياري. بدون TURN قد تفشل مكالمات الشبكات المقيدة أو بعض شبكات الجوال؛ STUN وحده لا يضمن الاتصال بينها. يجب استخدام بيانات TURN مؤقتة عند تحويل هذه التجربة إلى خدمة عامة.

HTTPS مطلوب للميكروفون خارج localhost. لا توجد حسابات موثقة أو مدفوعات أو إشراف إنتاجي. الرصيد والهدايا تجريبية. رفع المقاطع مخفي في النسخة المستضافة؛ الملفات الأصلية محفوظة ولا ندّعي تخزينها على Vercel.

## التحقق

```sh
npm run build
npm test
```

25 اختبارًا تشمل سلوك التشغيل المحلي وحالة النسخة السحابية: استقلال الغرف، إرسال إشارات WebRTC، ملكية الاتصال، سعة الغرفة، الدردشة، الهدايا وعدم خصمها مرتين عند إعادة الطلب، PK، مغادرة المشاركين وانتهاء الاتصالات القديمة.

ملفات التحقق والصور القادمة من الأرشيف تصف النسخة الأصلية قبل هذا التعديل. لا تُعد دليلًا على اختبار النسخة الحالية أو اتصال الصوت عبر الإنترنت. يحتاج التحقق النهائي للصوت جهازين وشبكتين حقيقيتين، وإعداد TURN عند الحاجة.
