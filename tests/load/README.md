# اختبارات الضغط المحافظة

هذه السيناريوهات تقيس مسارات القراءة العامة ومصافحة Engine.IO فقط. لا تنشئ
غرفًا، ولا ترسل إجابات، ولا تغيّر بيانات الموقع.

يجب تحديد العنوان صراحة، ويفضل البدء بعنوان محلي أو تجريبي:

```powershell
$env:BASE_URL = 'http://localhost:3000'
$env:VUS = '2'
$env:DURATION = '20s'
pnpm loadtest:smoke
pnpm loadtest:realtime
```

اختبار `realtime-handshake.js` يتحقق من مصافحة Socket.IO عبر polling ثم يغلق
الجلسة مباشرة، وليس محاكاة كاملة لبروتوكول Socket.IO أو جولة لعب. الإعدادات
الافتراضية صغيرة عمدًا؛ لا ترفع عدد المستخدمين على الإنتاج دون نافذة اختبار
وموافقة صريحة.
