# تنظيم بنك الأسئلة — سكربت Supabase

## التشغيل

1. افتح **Supabase Dashboard** للمشروع على `qurabia-production`.
2. من القائمة الجانبية: **SQL Editor** → **New Query**.
3. انسخ كامل محتوى [`curate-question-bank.sql`](./curate-question-bank.sql).
4. الصقه في المحرّر، ثم اضغط **Run** (أو `Ctrl+Enter`).
5. راجع مخرجات `RAISE NOTICE` والتقرير الإحصائي في الأسفل.

## ما يفعله السكربت

| القسم | العملية | النتيجة |
|-------|---------|---------|
| 0 | ضمان وجود مستخدم `seed@tahaddi.local` | ينشئه إن لم يوجد |
| 1 | أرشفة 4 أسئلة جغرافيا | `5 → 1` (قطع 80%) |
| 2 | إعادة صياغة 8 أسئلة بأنماط `scenario`/`curiosity` | تحديث prompt + options |
| 3 | إدخال 4 أسئلة جديدة في 4 فئات | ثقافة عامة، رياضيات، منطق، تقنية |
| 4 | تقرير إحصائي نهائي | توزيع الفئات + نسبة القطع |

## Idempotency

السكربت **آمن لإعادة التشغيل**:
- لا يكرّر الأرشفة (يتحقّق من `status = 'ARCHIVED'`).
- لا يكرّر إعادة الصياغة (يتحقّق من النص القديم قبل التحديث).
- لا يكرّر الإضافة (يتحقّق من النص الجديد قبل الإدراج).
- الفئات الجديدة تُنشأ مرة واحدة فقط.
