# نشر تطبيق «تحدّي» على App Store

التطبيق في `apps/mobile` مبني على Expo، ويُبنى ويُرفع عبر EAS.

## الإعداد الموجود

- `app.json`: المعرّف `com.qurabia.tahaddi` (مطابق لتطبيق سطح المكتب)، الأيقونة، شاشة البداية، اللغة العربية، وإعلان عدم استخدام تشفير خاص.
- `eas.json`: ملفا بناء `preview` للتوزيع الداخلي و`production` للمتجر، مع زيادة رقم البناء تلقائيًا.
- `assets/icon.png` بمقاس 1024×1024 دون شفافية، و`splash-icon.png` و`adaptive-icon.png`.

## خطوات النشر

1. التسجيل في Apple Developer Program.
2. إنشاء التطبيق في App Store Connect بالمعرّف `com.qurabia.tahaddi`.
3. من `apps/mobile`:

   ```bash
   npx eas-cli@latest login
   npx eas-cli@latest init
   pnpm build:ios
   pnpm submit:ios
   ```

   `eas init` يضيف `extra.eas.projectId` إلى `app.json`، وعند أول بناء يطلب EAS بيانات حساب Apple وينشئ الشهادات تلقائيًا.

4. اختبار البناء عبر TestFlight، ثم إرساله للمراجعة.

## بيانات المتجر المطلوبة

- رابط سياسة الخصوصية: `https://qurabia.com/privacy`.
- رابط الدعم: `https://qurabia.com/contact`.
- نموذج خصوصية البيانات في App Store Connect.
- لقطات شاشة لأجهزة iPhone بمقاس 6.9 بوصة، ولأجهزة iPad لأن `supportsTablet` مفعّل.
- الاسم والوصف والكلمات المفتاحية بالعربية، والتصنيف العمري.

## وظائف التطبيق

يلعب اللاعب الجولة كاملة داخل التطبيق دون الخروج إلى Safari:

- [x] الانضمام بالاسم ورمز الغرفة عبر `POST /api/live/join`، مع تعبئة الرمز تلقائيًا من روابط `tahaddi://join/CODE` و`https://qurabia.com/join/CODE`.
- [x] الجولة المباشرة: السؤال، الصورة، المؤقت المتزامن مع ساعة الخادم، والإجابة عبر `POST /api/live/[sessionId]/room`.
- [x] كشف الإجابة الصحيحة، النقاط المكتسبة، ونسب اختيار كل إجابة.
- [x] لوحة الصدارة والترتيب النهائي.
- [x] حالة الاتصال: إعادة المحاولة تلقائيًا عند انقطاع الشبكة، وإيقاف الطلبات عندما يكون التطبيق في الخلفية.
- [x] تصفّح مكتبة الألعاب من `@tahaddi/domain`.
- [x] روابط الخصوصية والشروط والدعم في شاشة الانضمام.

لا يوجد تسجيل دخول ولا مدفوعات داخل التطبيق، فلا تنطبق شروط حذف الحساب (5.1.1) ولا الشراء داخل التطبيق (3.1.1). إذا أُضيف أي منهما لاحقًا فيجب تطبيقها.

## قبل الإرسال للمراجعة

1. نشر الموقع بعد دمج هذا العمل، لأن التطبيق يعتمد على `https://qurabia.com/api/live/join`.
2. تجهيز غرفة تجريبية مفتوحة لفريق Apple، ووضع رمزها وطريقة تشغيلها في خانة App Review Notes. بدون غرفة نشطة لن يتمكن المراجع من تجربة التطبيق وسيُرفض.
3. اختبار الجولة كاملة على جهاز حقيقي عبر TestFlight.

## توافق الإصدارات

إصدارات `react` و`react-native` و`react-native-safe-area-context` يجب أن تطابق ما تدعمه نسخة Expo SDK المثبتة، وإلا يفشل بناء iOS. الاختبار `src/expo-sdk-compat.test.ts` يتحقق من ذلك، والترقية تتم مع `expo` عبر `npx expo install --fix`.
