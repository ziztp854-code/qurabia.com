# دليل مهارات التصميم لـ Codex

هذا الدليل يكيّف أفكار ملف «تصاميم.pdf» المرفق، الذي يشرح الحركة ونظام التصميم والذوق لبيئة Claude Code. الملفات هنا مهارات مكتوبة للمشروع، مستلهمة من الأفكار العامة في الدليل؛ ليست نسخًا رسمية من مهارات Emil Kowalski أو Impeccable أو Taste، ولا تتطلب تثبيتها أو تشغيل أوامرها.

| موضوع الدليل | مهارة Codex في المشروع | متى تستخدم |
| --- | --- | --- |
| الذوق والاتجاه | `design-taste-codex` | تحديد الاتجاه والتنوع والكثافة والحركة بحسب الجمهور والهوية. |
| نظام التصميم والمراجعة | `design-system-codex` | بناء واجهة متسقة، أو مراجعة تصميمها وإمكانية الوصول والاستجابة. |
| الحركة | `design-motion-codex` | تصميم الأنيميشن أو تحسينه أو فحص التوقيت والاستجابة وتقليل الحركة. |

توجد المهارات تحت `.agents/skills/`، وهي مستقلة ويمكن طلبها بالاسم من Codex، مثل: «استخدم مهارة design-motion-codex لمراجعة حركة التتويج». اكتشاف المهارات الجديدة قد يتطلب بدء جلسة Codex جديدة أو إعادة تحميلها بحسب بيئتك.

للعمل المتكامل، ابدأ بالاتجاه إذا كانت المهمة تحتاج تحديده، ثم طبّق نظام المشروع، ثم صمّم الحركة، وأخيرًا راجع النتيجة بحسب نطاق الطلب. هذا ترتيب إرشادي، ولا يمنع تنفيذ مهمة محددة بمهارة واحدة. أوامر `/plugin` و`/impeccable` المذكورة في الدليل تخص Claude Code؛ لا تفترض أنها متاحة في Codex.

في مشروع تحدّي، تبقى `AGENTS.md` و`design.md` و`docs/design-system.md` و`docs/visual-excellence.md` والتوجيهات المباشرة للمستخدم مصادر المرجع. تحترم المهارات الهوية الحالية وRTL ومصدر بيانات الألعاب، ولا تفوّض أي نشر أو إعادة تصميم شاملة بحد ذاتها.
