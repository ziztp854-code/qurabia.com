# اختبار تكامل مفضلة الألعاب

يحفظ مسار `/api/game-favorites` المفضلة للحساب الحالي بعد التحقق من الجلسة. يتطلب الجدول ترحيل `20261028100000_game_favorites`؛ يجب تطبيقه وفق إجراءات نشر قاعدة البيانات قبل تفعيل الميزة في بيئة منشورة.

لاختبار المسار بقاعدة PostgreSQL معزولة، جهّز قاعدة محلية باسم `favorites_test` أو `favorites_test_*` وطبّق ترحيلات المشروع عليها، ثم شغّل:

```sh
GAME_FAVORITES_TEST_DATABASE_URL='postgresql://USER:PASSWORD@127.0.0.1:5432/favorites_test' \
  pnpm --filter @tahaddi/web exec vitest run src/app/api/game-favorites/route.integration.test.ts
```

يرفض الاختبار عناوين الخوادم البعيدة وأسماء القواعد الأخرى، ولا يستخدم `DATABASE_URL` بديلًا. ينشئ حسابين تجريبيين بمعرّفات عشوائية ويحذفهما عند الانتهاء. يحاكي هوية الحساب في واجهة HTTP ويختبر الكتابة والقراءة والعزل بقاعدة فعلية؛ لا يعد اختبارًا لتسجيل الدخول أو اتصال الإنتاج.
