# Stable source assets

Prepared from the user's five-level reference with the built-in `image_gen` tool (transparent background extraction, one edit per level). These PNGs retain the tool's full resolution; they are not loaded by the application. `reference.png` is the unchanged supplied sheet.

Runtime files live in `apps/web/public/game-art/kingdoms/village/buildings/stable-l1.webp` through `stable-l5.webp`. Conversion uses the existing Next.js Sharp runtime: width 768px, preserved aspect ratio, WebP quality 88, alpha quality 100, effort 6. No application dependencies were added.

Each sprite contains only its stable, static horses and attached yard/details, without the sheet's title plaques. Runtime placement stays x454/y516/111×67, bottom-center anchor0.5/1, z-index583. Only these stable slots opt into uniform contain scaling. Server state and training remain owned by barracks; horses depicted in the artwork are decorations.
