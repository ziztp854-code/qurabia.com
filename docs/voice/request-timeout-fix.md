# معالجة مهلة طلبات الغرف — 21 أكتوبر 2026

أبلغ المستخدم عن «انتهت مهلة الطلب. حاول مرة أخرى» عند دخول الغرفة أو إعطاء المايك بعد إصدار `5c7a311`. أظهرت سجلات الإنتاج أخطاء `PrismaClientKnownRequestError` في مسار أحداث الغرفة. كان التسجيل السابق يحفظ اسم الاستثناء فقط؛ لا يجزم هذا التقرير برقم خطأ Prisma قبل رصده في الإصدار المصحّح.

## التغيير

- تحديث الحضور مرة كل 10 ثوانٍ بدل كتابة حالة الغرفة مع كل قراءة دورية. يبقى عمر الحضور 90 ثانية، وتظل صلاحية الحساب والعضوية الحالية مفحوصة.
- لا يرفع توقيت فحص الصوت وحده رقم مراجعة الغرفة. يُحدّث حقل التوقيت فقط بـ`jsonb_set`؛ أي تغيير فعلي في سجل رموز الصوت يظل يرفع المراجعة ويستخدم القفل المشترك.
- الفحص الدوري يستخدم قفلًا غير منتظر؛ إذا كان فحص/أمر آخر يمسك القفل يتجاوزه. المنح والكتم والإزالة وإصدار الرموز تظل تستخدم القفل الإلزامي والتحقق الحالي، ولا يُتجاوز فرض الصلاحيات.
- مهلة معاملة تعديل الغرفة 20 ثانية، مع انتظار اتصال أقصاه 5 ثوانٍ. مهلة العميل لأوامر الدخول/المايك والصلاحيات 45 ثانية لتستوعب حدود معالجة الخادم، بينما القراءة والدردشة تبقيان 10 ثوانٍ. لا إعادة تلقائية لطلبات قد تكون حُفظت بالفعل.
- تسجيل رمز Prisma بصيغة `P####` فقط، دون رسالته أو عنوان الاتصال أو المعاملات أو بيانات الحسابات.
- لا يصبح زر تسجيل الخروج قابلًا للضغط قبل ربط معالج React. يعالج ذلك فقدان نقرة مبكرة بعد ظهور HTML؛ اختبار GitHub السابق أخفق في انتظار العودة للرئيسية بعد الضغط.

## التحقق المحلي

- 88 اختبارًا في 7 ملفات: عميل الغرفة، LiveKit، حدود HTTP، مسار الأحداث، واجهة الصوت، صلاحيات الغرفة وهوية الحساب.
- 7 اختبارات PostgreSQL في قاعدة `voice_test_apple_design` المحلية المعزولة، تشمل حصة الغرف والتراجع والتزامن. تشمل الحالات الجديدة قراءات حضور متزامنة دون كتابة، تجديد الحضور المستحق، فصل التوقيت عن مراجعة الصلاحيات، وتجاوز الفحص الدوري لقفل مشغول مع استمرار انتظار الأمر الإلزامي.
- TypeScript وبناء الإنتاج المحلي وفحوص الملفات العامة ناجحة. Lint بلا أخطاء، مع التحذيرين السابقين خارج النطاق.
- متصفح Chromium مع تأخير تحميل JavaScript عمدًا: زر الخروج معطل قبل hydration، ثم يعمل ويعود للرئيسية، وتُحمى صفحة البروفايل بعد الخروج.
- اختبار حسابين محليين لإعطاء المايك ناجح: المستمع غير المخوّل 403؛ المنح من صاحب الغرفة 200؛ المتلقي متحدث مكتوم بمقعد متاح. الصور المحدّثة في تقرير Apple Design.

لا توجد ترحيلات أو اعتماديات جديدة أو تغييرات في قواعد المسابقات. النقل الفعلي للصوت وحالة شبكة جهاز المستخدم يلزمان تحققًا بعد النشر؛ نجاح البيانات المحلية لا يثبت وحده زوال رسالة المستخدم في الإنتاج.
