# الهدايا التجريبية

تتوفر أربع هدايا مجانية: وردة وتصفيق ونجمة وتاج. يفتح زر «الهدايا» بجانب حالة الصوت نافذة لاختيار عضو وهدية؛ يمكن أيضًا فتحها من ملف العضو، أو اختيار نفسك للتجربة الفردية. لا توجد محفظة أو عملات أو أسعار أو مكافآت حساب أو شراء أو خصم رصيد.

يرسل العميل `giftId` و`recipientId` فقط عبر مسار أحداث الغرفة الحالي. يتحقق المخطط الصارم من قائمة الهدايا، ويأخذ الخادم هوية المرسل واسم المستلم من عضوية الغرفة. يُرفض المرسل غير المنضم والمستلم الذي غادر والغرفة المنتهية والدردشة المغلقة. تخضع العملية للمصادقة وفحص الأصل وحد الطلبات الموجود. يحد الخادم الإرسال إلى مرة كل خمس ثوانٍ لكل عضوية؛ الحذف لا يزيل المهلة، والمغادرة وإعادة الانضمام تنشئ عضوية جديدة. الهدايا ليست عملية مالية أو دفتر رصيد.

تُحفظ الهدية كرسالة ذات بيانات إضافية اختيارية في حالة JSON الموجودة، ضمن آخر200 رسالة، دون جداول أو هجرة جديدة. لذلك تعمل الغرف والرسائل القديمة دون تحويل. يصل السجل لأعضاء الغرفة عبر جلب اللقطات المعتاد، وتعمل الردود والتفاعلات والتثبيت والحذف والإبلاغ وحظر رسائل المرسل كما في الدردشة. تبقى أسماء الهوية نصًا معزول الاتجاه، ولا تُعرض HTML من المستخدم. صورة الإيموجي تعتمد على جهاز العرض؛ ليست أصلًا مصورًا مخصصًا.

تحتوي الواجهة على اختيار radio أصلي وحقل مستلم مسمى وحالات إرسال/فشل/نجاح؛ لا تعلن النجاح قبل رد الخادم. تُعطل الإرسال إذا غادر المستلم أو فقد المستخدم العضوية أو أُغلقت الدردشة. تُعرض بطاقة الهدية في الدردشة بحركة دخول قصيرة تحترم reduced motion، دون صوت إضافي أو نوافذ فوق الألعاب. لا يتغير موضع AudioSession أو مفاتيحه أو اعتماداته.

## التحقق

نجحت101 حالة في12 ملفًا للصوت والواجهة والمسارات، مع ESLint للنطاق المعدل وبناء web. لا يتطلب هذا التحديث هجرة قاعدة بيانات أو اعتمادًا جديدًا.

تغطي الاختبارات هوية السجل وصلاحيات العضوية والحظر والمهلة بعد حذف السجل وحدها عند خمس ثوانٍ، والحفظ ضمن200 رسالة، ورفض أسماء الهدايا والحقول المالية أو الهويات المزيفة. تغطي الواجهة الاختيار والإرسال الفردي والفشل والمستلم المغادر والعرض الآمن، ويؤكد اختبار جلسة الصوت عدم إعادة الاتصال أو تبديل المايك أثناء الإرسال وتحرير الحوار أثناء فتح لعبة. هذه اختبارات شفرة وReact مع SDK بديل، وليست ميكروفون جهاز فعلي.

مراجعة Art Director / Visual QA ذاتية للشفرة والتوكنات وRTL: الحالة **unverified**. لا تتوفر أداة متصفح متصلة لتصوير سطح المكتب/الجوال أو فحص320px/200% والتركيز والتباين بصريًا؛ لا توجد درجة بصرية مفترضة. يلزم أيضًا تجربة هدية بين حسابين فعليين في غرفة مأهولة.
