# تنسيق غرفة تحدي لايف

يشمل هذا التحديث واجهة الغرفة فقط: بطاقات المايكات، قائمة الأعضاء والدردشة. يستخدم رموز voice الحالية وخط Cairo ومكون Avatar، مع ذهب للمضيف وسماوي للمتحدث الفعلي. تبقى جلسة AudioSession وشريط الصوت المستمر خارج تخطيط الغرفة دون تغيير في هويتهما أو دورة حياتهما.

- للمايك بطاقة ثابتة المساحة تعرض الاسم والدور وحالة مكتوبة: يتحدث الآن، مكتوم أو المايك مفتوح. حالة الحديث تعتمد على حدث المتحدثين من LiveKit؛ فتح المايك يعكس حالة العضو ولا يضمن استقبال الآخرين للصوت.
- تعرض قائمة أعضاء الغرفة المتحدثين والمستمعين معًا، مع البحث بالاسم وحالة رفع اليد وفتح ملف العضو. لا يؤثر ترشيح القائمة في مقاعد المايكات أو العضوية.
- تعرض الدردشة رسائل أوضح وتوقيتًا مقروءًا وعزلًا لاتجاه الأسماء المختلطة، مع الحفاظ على الردود والتفاعلات والتثبيت والإبلاغ. تبقى إجراءات الرسالة متاحة دون اشتراط hover.
- تتدرج شبكة المايكات إلى ثلاثة ثم عمودين على الشاشات الضيقة، وتلتف بطاقات الأعضاء. أهداف الأزرار 44px وحالات التركيز ظاهرة. لا تُضاف حركة أو طلبات شبكة أو مكتبات.

## التحقق

نجحت91 حالة في11 ملفًا عبر `pnpm --filter @tahaddi/web exec vitest run src/lib/voice src/components/voice src/app/api/voice`. تشمل حالة جديدة عرض المتحدث والمستمع والبحث مع بقاء المقعد، والحالات السابقة لاستمرار الصوت أثناء الألعاب وتحرير تركيز الدردشة. نجح ESLint للملفات المعدلة وبناء web مع فحوص تسرب إعدادات الخادم وميزانية ألوان CSS.

مراجعة Art Director / Visual QA: مراجعة ذاتية للشفرة والتوكنات وRTL. لا تتوفر أداة متصفح متصلة، لذا لا توجد صور قبل/بعد أو قياسات فعلية للشاشات أو الأداء أو التباين أو تكبير200%. الحالة **unverified** ولا تمنح درجة أو قبولًا بصريًا نهائيًا. يلزم فحص غرفة مأهولة وأسماء ورسائل طويلة ومقاعد مقفلة/فارغة وحوار دردشة مع لوحة مفاتيح الجوال عند320px وعلى سطح مكتب، إلى جانب التنقل بالتركيز. نجاح jsdom والبناء ليس دليلًا بصريًا أو اختبار ميكروفون فعلي.
