# نشر نسخة الغرف

أذن المستخدم برفع ونشر هذه الميزة بعد المراجعة المحلية. الفرع `feat/tahaddi-live-platform` مبني على آخر إصلاح للممالك `426ae9a`، وطلب المراجعة [66](https://github.com/ziztp854-code/qurabia.com/pull/66). سجلات المراجعة المحلية السابقة توثق حالة العمل قبل هذا الإذن، وليست تأكيدًا لحالة النشر الحالية.

المشروع المقصود على Vercel هو `tahaddi-platform-realtime`، والموقع `qurabia.com`. تبقى بيانات الحسابات الحالية مصدر المصادقة. لا تحتوي النسخة مفاتيح LiveKit أو إعدادات localhost للنشر العام.

## قاعدة البيانات

تستدعي خدمة web في `vercel.json` فحص `voice-production-schema.mjs` قبل البناء. يعمل فقط عند `VERCEL_ENV=production` و`VOICE_SCHEMA_DEPLOY=1`، ويستخدم بيئة الخادم دون قراءة ملفات .env أو عرض القيم. يتجاوز المعاينات حتى لا تطبق مهاجراتها على قاعدة الإنتاج المشتركة.

يسمح الفحص فقط بهجرة `20261018090000_voice_rooms` المضافة إلى مخطط مطبق مسبقًا. إذا كانت مهاجرات أخرى معلقة، أو هجرة غير مكتملة، أو جداول صوت جزئية، يوقف النشر دون إصلاح تلقائي أو إعادة ضبط. إذا كانت الهجرة مكتملة والجداول الأربعة موجودة، لا يغير شيئًا. يستخدم إعداد Prisma منفصلًا يمنع استبدال وجهة النشر بملف بيئة محلي. الإضافة تنشئ جداول ومفاتيح وفهارس فقط؛ لا تعيد كتابة حسابات أو بيانات ألعاب.

العودة إلى نسخة Vercel السابقة ممكنة دون حذف جداول الصوت. لا تجرِ down migration أو تحذف بيانات الغرف عند التراجع عن الواجهة.

## الصوت

لم تكن متغيرات LiveKit العامة أو الخاصة أو مفاتيحها موجودة في Vercel عند الفحص. تظهر حالة «الصوت يحتاج إعداد الخدمة» حتى تكتمل الاستضافة الجديدة. لا يعني نجاح نشر الواجهة نجاح الميكروفون العام. راجع [خيارات الاستضافة](hosting.md) قبل اختيار المزود وتهيئة CSP وWebhook والعزل أو ضوابط الإلغاء المكافئة واختبارها.

يلزم بعد إعداد المزود اختبار جهازين وشبكتين والصلاحيات والاستمرار أثناء اللعب. قبول المتصفح والأجهزة ما زال غير متحقق؛ لا تغيّر ذلك اختبارات jsdom أو نجاح البناء أو تشغيل SFU المحلي.
