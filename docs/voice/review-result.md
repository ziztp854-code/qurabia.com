# تحدي لايف — نتيجة المراجعة المحلية

تاريخ التقرير: ١٨ أكتوبر ٢٠٢٦. الفرع `feat/tahaddi-live-platform`، مبني على `e3db6b29d6a845bce24e16dc5c4df915d54eb465`. التعديلات محلية؛ لم يُنفّذ commit أو push أو دمج أو نشر لهذه النسخة.

## ما أصبح متاحًا

واجهة عربية RTL بهوية داكنة وذهبية، أغلفة محلية ونسخ للجوال، استكشاف الغرف وإنشاؤها، الغرف الخاصة والدعوات، المقاعد وطلبات التحدث والأدوار والإشراف، الدردشة والتفضيلات والسجل. تعتمد على حسابات NextAuth وقاعدة Prisma الحاليين. الصوت متصل بخادم LiveKit محلي وبوابة تتحقق من العضوية والصلاحيات الحالية عند الاتصال وإعادة الاتصال. مؤشرات التحدث مستمدة من أحداث الصوت، وأعداد المشاركين من بيانات الغرفة.

أضيف استمرار جلسة المايك عند التنقل إلى الألعاب عبر روابط الموقع، مع شريط تحكم مشترك دون إعادة الانضمام للغرفة. [سجل هذا التحديث](persistent-voice.md) يوضح السلوك وحدود الاختبار وتغيير سياسة الميكروفون اللازمة لذلك.

توجد حالات واضحة لغياب إعداد الصوت، رفض الميكروفون وإعادة الاتصال. تُعاد معالجة أغلفة المستخدمين إلى WebP مع قيود الحجم والملكية. تفاصيل البنية والحدود في [README](README.md)، وتفاصيل الخدمة في [audio-local.md](audio-local.md).

## أدلة التحقق

| الفحص | النتيجة وحدودها |
| --- | --- |
| مجموعة اختبارات الويب العامة | ٢٤٩٧ ناجحًا، ٧١ متجاوزًا؛ نُفذت قبل التصحيحات الأخيرة التي أعيد فحص نطاقها |
| الاختبارات النهائية الخاصة بالصوت والغرف | ٥٤ ناجحًا في ٧ ملفات |
| استمرار الصوت مع الألعاب | ١٠ اختبارات تنقل إضافية ناجحة؛ مكونات React فعلية مع SDK وشبكة وهميين، دون متصفح أو ألعاب فعلية |
| بوابة الإشارات | ٣ اختبارات ناجحة، تشمل مرور WebSocket فعلي وتبادل القبول عبر HTTP |
| HTTP مع الحسابات وقاعدة البيانات الفعليتين | ٦ اختبارات ناجحة؛ أعيد اختبار حالتي إلغاء الجلسة وحد المعدل بعد توسيع تأكيداتهما |
| التطبيق ← قاعدة البيانات ← البوابة ← SFU | ٥ تحققات ناجحة: قبول المتحدث، مرور SFU، خفض صلاحيات الرمز القديم، رفض العضو المحذوف ورفض الجلسة الملغاة |
| الصوت الآلي عبر SFU والبوابة | ١١ تحققًا ناجحًا؛ مصدران مولدان 440/660 Hz على جهاز واحد، استقبال PCM فعلي، كتم/إلغاء كتم ومغادرة وضبط إعادة استخدام الرموز |
| البناء وTypeScript وESLint | نجحت، بما فيها ميزانية CSS وملفات المسارات الجديدة |
| المتصفح والجهازان الفعليان | لم يُنفذا؛ لا توجد لقطات شاشة فعلية أو درجة قبول بصري |

تقرير SFU المباشر يحتفظ بنتيجة تشخيصية فاشلة لإعادة استخدام رمز بعد حذف العضو. لهذا لا يُسمح بالوصول العام إلى منفذ الإشارات الداخلي؛ المسار المعتمد يمر بالبوابة. تقرير البوابة المنفصل يختبر رفض الرموز القديمة والمحدثة بعد حذف العضوية وتغيير الجلسة. هذه الأدلة متكاملة وليست اختبارًا واحدًا متصلًا يلتقط ميكروفون المتصفح.

ملف WAV المرفق عينة نغمة اختبار مولدة استُقبلت من SFU؛ ليس تسجيلًا بشريًا. لا تتضمن حزمة المراجعة مفاتيح الخدمة أو قواعد البيانات أو رموز الدخول.

## فتح النسخة في بيئة المراجعة الحالية

تطبيق Next على `http://127.0.0.1:3000/voice/`، البوابة على المنفذ7890، وإشارات LiveKit الخاصة على loopback7880. هذه عناوين داخل بيئة العمل وليست رابطًا عامًا للمشاركة أو عنوان localhost لهاتفك.

قاعدة المراجعة المنفصلة `voice_test_review`؛ لا تستخدم حسابات الإنتاج أو بياناته. حُذفت حسابات الاختبار المؤقتة بعد التحقق. يمكن إنشاء حساب محلي من `/auth/sign-up/` ثم فتح الغرف. لا تُنشأ نشاطات وهمية في شاشة الاستكشاف.

الخدمات أُبقيت للمراجعة. إذا توقفت عملية Next فقط، شغّلها من جذر المشروع بعد التأكد أن المنفذ3000 متاح:

```sh
set -a
source /tmp/tahaddi-voice-local/session.env
set +a
DATABASE_URL=postgresql://postgres:postgres@127.0.0.1:5432/voice_test_review \
DIRECT_URL=postgresql://postgres:postgres@127.0.0.1:5432/voice_test_review \
NEXTAUTH_URL=http://127.0.0.1:3000 AUTH_URL=http://127.0.0.1:3000 \
NEXT_PUBLIC_SITE_URL=http://127.0.0.1:3000 \
pnpm --filter @tahaddi/web exec next dev --hostname 0.0.0.0 -p 3000
```

كلمة مرور PostgreSQL في الأمر تخص حاوية التطوير المحلية فقط. لا تنقل هذا الإعداد إلى الإنتاج. خطوات تشغيل SFU والبوابة موجودة في [توثيق الصوت](audio-local.md). ملف الإعداد المؤقت خاص بهذه الآلة؛ يلزم توليد مفاتيح جديدة وتهيئة الخدمة عند الانتقال لآلة أخرى.

## ما يلزم قبل القبول النهائي

يلزم تصوير الواجهة الفعلية للكمبيوتر والجوال وعرض320px، والتحقق من RTL والتركيز ولوحة المفاتيح والتكبير200٪، وتجربة ميكروفونين على جهازين وشبكتين، والكتم والمغادرة وإعادة الاتصال وتغيير الجهاز. [سجل القبول](acceptance.md) يحدد الحالات المطلوبة. أداة التحكم بالمتصفح غير متاحة في الجلسة، ولم تُستبدل صور الأغلفة أو نتائج الاختبارات بلقطات واجهة مزعومة.

النسخة مخصصة لمراجعة محلية محدودة: الحضور والدردشة باستعلامات كل٢٫٥ ثانية، حتى٢٥٠ عضوًا و١٦ مقعدًا وأحدث٢٠٠ رسالة. لا يوجد قياس تحميل أو ادعاء جاهزية تشغيل واسعة. تسوية الحضور تعتمد على الطلبات، ويحتاج إغلاق نافذة السباق بعد القبول إلى Webhook موقّع؛ لا ندعي إلغاء صلاحية لحظيًا بلا نافذة سباق. تحتاج بيئة خارجية إلى HTTPS/WSS وTURN وعزل منفذ SFU ومراجعة CSP وتشغيل ومراقبة مناسبة.

لم تُضف مستويات أو عملات افتراضية بلا مصدر موثوق في الحسابات الحالية، ولا صلاحية خاصة بالملف الشخصي دون تطبيقها فعليًا. بعض إعدادات API أوسع من نموذج التعديل المعروض. لا يوجد قبول نهائي أو موافقة ضمنية على النشر.

## حزمة المصدر

`tahaddi-live.patch` يحتوي جميع تغييرات الميزة، بما فيها الملفات الجديدة والصور الثنائية. يطبّق على نسخة من المراجعة الأساسية المذكورة أعلى التقرير بعد `git apply --check` ثم `git apply`. لم يُعدّل فهرس Git الفعلي عند إعداد الرقعة. `changed-files.txt` يسرد ملفات الرقعة، ولا تشمل ملفات AGENTS/CLAUDE التي ولّدها Next تلقائيًا أثناء التطوير.
