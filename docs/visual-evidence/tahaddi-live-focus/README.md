خط الأساس `68b7234f`، الفرع `codex/hallmark-live-ui-polish`. تركز هذه الجولة على اكتشاف الغرف وبطاقاتها وحالات البحث/الفراغ/الخطأ ووضوح المقاعد داخل الغرفة. لم يُضف تعديل إلى بث المسابقة أو منطقها. [التدقيق الأولي](AUDIT.md) · [المراجعة المستقلة](INDEPENDENT-REVIEW.md).

## التعديلات

كود الإنتاج محصور في3 أوراق CSS:

- `voice-lobby.module.css`: فصل بيانات البطاقة عن الغلاف على الجوال بدل تراكبها، وضبط الغلاف وهوية المضيف، وتكبير معلومات الغرف والتصنيفات والبحث. بقي الغلاف والعنوان وزر الدخول والمفضلة وروابطها ووظائفها كما هي؛ زر الدخول المخفي أصلًا على الجوال لم يُحذف، ويبقى الدخول عبر الغلاف والعنوان.
- داخل الاكتشاف نفسه: رأس صغير يلتف عند الحاجة بدل فرض صفين، ودعوة إنشاء تستخدم المساحة الجانبية المتاحة وتعود إلى عمود واحد مع تكبير الخط. تحسّن حد البحث برمز لوني موجود، وفُصل إجراء تسجيل الدخول عن جملة الحالة الفارغة، وأصبحت رسالة الخطأ تسمح بالتفاف يحفظ زر المحاولة.
- `live-room-mobile.module.css` و`live-room-desktop.module.css`: رفع أسماء/طلبات المقاعد خطوة صغيرة إلى12px للجوال و13px للكمبيوتر، وأرقام المقاعد إلى11px. لا تغيير لشبكة المقاعد أو الدردشة أو الصوت.

بقيت ألوان الذهب والسماوي والأسطح الداكنة والخطوط الأصلية وRTL. لا تعديل TSX أو API أو Socket.IO أو WebRTC أو قاعدة بيانات أو روابط أو منطق لعبة. لم تتغير تبعيات المشروع.

## قياسات فعلية

- أول بطاقة على360px تقدمت منy551.5 إلى486.45، بنحو65px.
- بطاقة الكمبيوتر343→321px، والغلاف150→128px.
- بطاقة الجوال185→222.4px في الحالة الملتقطة: زيادة مقصودة مقابل متن14px وبيانات12px وتفاصيل لا تتداخل مع الغلاف؛ غلافها النهائي88px وهوية المضيف48px، بعد تقليل الكثافة من دفعة أولى بلغت246px.
- نص البحث14px على الكمبيوتر و16px على الجوال، وهدف المفضلة44×44px. الأسماء الطويلة وتكبير200% لا يسببان تجاوز الصفحة أو قص البطاقة/العنوان/المضيف في الفحص.
- حد البحث مقابل تعبئته8.96:1. فُحص تحذير Hallmark المتعلق بالنص فوق تدرج زر الإنشاء: الحبر الفعلي داكن، والتدرج بين رمزين ذهبيين معتمدين؛ أدنى نسبة حتى مع تضمين الرمز الذهبي الأغمق5.98:1. هذا فحص لأزواج محددة، لا شهادة تباين لكل الخلفيات المصوّرة.

## الفحوص

- Hallmark، قبل وبعد مع render فعلي و`--kept`: Floor **1→0** ضمن ورقة الاكتشاف والمسار المصوّر فقط؛ الروابط11/11 والحقول2/2 والعناوين7/7 محفوظة. Reflex17→3، وWARN2 باقية، و15 ملاحظة نطاق. تغير تصنيف القواعد التركيبية بسبب عمقpolish لا يعني إصلاح14 عيبًا مستقلًا. [قبل](hallmark-before.json) · [بعد](hallmark-after.json).
- البواقي: قواعد `:active` غير موحدة في نطاق الورقة المفحوصة، والتفاف طبيعي لعناوين الغرف، وتسميات تنقل صغيرة متوارثة. تحذير التدرج خضع للقياس أعلاه، وغياب `text-wrap: balance` ملاحظة إنهاء على عنوان معتمد؛ لم نعد كتابة العلامة أو النسخ لإرضاء الأداة. خرج sloplint بالحالة1 بسبب النتائج غير المغلقة؛ لا ادعاء باجتياز كامل للمشروع.
- **26 اختبار وحدة ناجحًا** في `voice-ui` و`voice-room-audience` و`voice-chat`.
- **3 اختبارات سطوح ناجحة** عبر `playwright.tahaddi-surfaces.config.ts`، تشمل ترتيب الغرف والبحث ومقاسات320/390/1440 والنص200%.
- **5 اختبارات غرفة ناجحة، وواحد متخطى** عبر `playwright.live-room.config.ts`، تشمل لوحة المفاتيح والتركيز والهوية العربية الطويلة والنص200%. المتخطى مخصص لوضعfinal ولم يُحسب نجاحًا. [قياسات الغرفة](room-responsive-checks.json) · [لوحة المفاتيح](room-keyboard-checks.json).
- بناء الإنتاج `pnpm --filter @tahaddi/web build` نجح بعد آخر إصلاح، متضمنًا TypeScript وفحص الحزم العامة وميزانية CSS. Prettier و`git diff --check` ناجحان.

لم تُعدل الاختبارات لجعل الصقل ينجح، وأُعيدت مخرجات الاختبارات القديمة المتولدة إلى حالتها الأصلية. البيانات والصور الجديدة في هذا المجلد فقط. بصمات ملفات الربط الرئيسية لا تزال مطابقة، وdiff الإنتاجCSS فقط؛ هذا يحفظ التوصيلات ولا يثبت اتصال صوت/شبكة حقيقيًا جديدًا.
