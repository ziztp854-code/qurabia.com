# تدقيق متابعة — تحدي لايف

خط الأساس `68b7234f`، الفرع `codex/hallmark-live-ui-polish`. هذه الجولة تختص باكتشاف الغرف وبطاقاتها والغرفة الصوتية؛ لا تعديل إضافي على شاشة بث المسابقة.

دُرست القواعد النهائية في `voice-lobby.module.css` و`voice.css` ومكوّني VoiceLobby وRoomCard، مع إعادة قراءة سجل Hallmark ونظام Prestige Live. لم تُعدّل ملفات إنتاج قبل صور هذه الجولة.

الصور تستخدم VoiceLobby الفعلي وبيانات الغرف الموجودة أصلًا في `e2e/fixtures/tahaddi-surfaces-data.ts` عبر proxy محلي أمام Vite. فُحصت حالات الغرف الممتلئة، والفراغ، وتعذر التحميل، والبحث دون نتائج، والغرفة على360×640 و1920×1080. هذه بيانات تجريبية، لا غرف إنتاج أو أرقام استخدام حقيقية. بخلاف الجولة السابقة، وفر مصدر البيانات المحلي مخزون الغرف عند تدقيق البطاقات. لا قاعدة بيانات أو خدمات صوت حقيقية.

نتائج تستحق الصقل:

1. البطاقة على الجوال تضع معلوماتها فوق مساحة صورة المضيف بتموضع مطلق؛ تتداخل صورة الهوية وعدد المستمعين والعنوان. فصل منطقتي الغلاف والمعلومات داخل البطاقة نفسها يعالج هذا دون تغيير ترتيب أقسام الصفحة أو الروابط.
2. اسم المضيف10px، وحالة البث9px، وتلميح الترتيب9px والفلاتر11px ضعيفة القراءة. يلزم سلم أوضح ومسافات تسمح بالعربية الطويلة.
3. صور الغلاف على الكمبيوتر تشغل150px لكل بطاقة هوية افتراضية؛ يمكن تقليل المنطقة إلى128px وتخصيص المساحة للعنوان والبيانات.
4. حد البحث منخفض التباين وفق Hallmark:1.88:1. يستخدم الإصلاح لونًا موجودًا في النظام.
5. رسائل الفراغ والخطأ صغيرة، والخطأ لا يلتف مع زر المحاولة. يلزم حجم14px وتفاف يحفظ وصول الزر.
6. تسميات المقاعد داخل الغرفة ما زالت11/12px، ورقم المقعد10px؛ يمكن رفعها خطوة صغيرة دون تعديل الشبكة أو المحادثة أو الصوت.

Hallmark قبل:1 Floor FAIL، و17 Reflex و2 WARN في نطاق ورقة الاكتشاف ومسارها المصوّر. النتيجة الخام المرفقة هي المصدر لأعداد الروابط والحقول. المراجعة المستقلة منفصلة عن التنفيذ وتراجع الصور بعد الصقل.

النطاق المقترح: ثلاث أوراق CSS فقط: `voice-lobby.module.css` و`live-room-mobile.module.css` و`live-room-desktop.module.css`. لا تعديل TSX أو بيانات أو منطق أو روابط أو Socket.IO/WebRTC. لا رفع أو نشر أو دمج.
