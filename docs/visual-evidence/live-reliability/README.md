# إصلاحات اعتمادية تحدي لايف

الفرع: `codex/live-reliability-fixes`. اعتمد المالك التنفيذ بعد المراجعة بتاريخ 2026-10-26. لم يحدث رفع أو دمج أو نشر أو تعديل لقاعدة بيانات الإنتاج.

## ما تغيّر

- **هوية البلوت:** الاسم ورمز الغرفة لا يستعيدان توكن المضيف المفصول. مقعده محجوز للاستئناف بالتوكن الصحيح؛ استبدال الضيف المشروع يصدر توكنًا جديدًا.
- **قفل البلوت:** انتهاء انتظار القفل يعيد `ROOM_BUSY` دون تنفيذ أو حفظ أو بث. صار `resume` داخل القفل أيضًا. يحفظ الـgateway اتصال اللاعب عند الانشغال؛ تكرار المحاولة التلقائي مقصور على أعمال خلفية محروسة بالهوية أو إصدار الحالة، دون إعادة أوامر المستخدم تلقائيًا.
- **انتقالات المسابقة:** الكتابات مشروطة بحالة الجلسة والسؤال ووقت البداية والكشف والتقدم. `FINISHED` نهائية؛ تحرير قفل Redis يتطلب ملكية صحيحة، وإسقاط الحالة يرفض السؤال أو المرحلة الأقدم. الاستعادة تتحقق من DB ولا تعتمد على تشابه اسم المرحلة. يحمي العميل النهاية والإجابة من أحداث البدء القديمة أو المكررة.
- **استمرارية الدردشة:** تحفظ ذاكرة تملكها الغرفة المسودة والرد ومعرّف الطلب خلال إعادة الانضمام لنفس الغرفة والمستخدم. الخروج الصريح أو تغيير النطاق يمسحها؛ الإقرار المتأخر لا يحيي حالة ملغاة. لا تخزين دائم ولا إرسال تلقائي. تنبيه الاتصال عربي ومستقل عن خطأ الإرسال، ويتعافى دون محوه.
- **اختبارات CI:** مهمة مستقلة بقاعدة PostgreSQL 16 باسم `voice_test_ci`، وتجهيز بترحيلات المشروع القائمة وبناء الحزم المشتركة قبل تشغيل الاختبارات. المشغّل المخصص يفشل عند غياب إعداد القاعدة بدل تخطي الحزمة كاملة. المشغّل العام يبقي اختبارات DB الاختيارية كما هي.

لم يتغير مخطط DB أو العقود العامة أو معاملة الإجابة والنقاط. حُفظ معنى موعد الكشف في HTTP؛ لا يُفسّر وحده بوصفه موعد لوحة نتائج.

## أدلة التحقق

فشلت اختبارات الانحدار المعنية قبل الإصلاح، ثم نجحت بعده:

- البلوت: 87 اختبارًا عبر أربع مجموعات؛ استعادة المضيف والضيف، التزاحم، المحاولة اليدوية بنفس معرّف الأمر، الانشغال عند تغيير الغرفة، والمؤقتات المحروسة.
- المسابقة: 37 اختبار Jest و28 اختبار Vitest موجهًا؛ سباق البدء والإنهاء، ملكية منتهية، نجاح DB ثم فشل Redis، الاستعادة، تنافس HTTP، والأحداث القديمة في العميل.
- الدردشة: اختبارات وحدة ومتصفح تشمل حفظ رسالة مع فقد إقرارها، انتهاء العضوية وإعادة الانضمام ثم إعادة المحاولة بنفس requestId مع ظهور رسالة واحدة. هذا اختبار HTTP اصطناعي، وليس دليلًا على WebRTC إنتاجي.
- واجهة الغرفة كاملة: 7 اختبارات Chromium ناجحة وواحد متخطّى، تشمل التجاوب واستعادة الدردشة.
- PostgreSQL: 9 اختبارات تكامل ناجحة على قاعدة جديدة في حاوية PostgreSQL 16 بذاكرة tmpfs؛ أُزيلت الحاوية. لم تُستخدم قاعدة التطبيق. فشل المشغّل عند غياب URL كما هو مقصود.
- Redis: خدمة RedisService المبنية فعليًا نجحت أمام Redis 7.4 معزول: رفض تراجع المرحلة والسؤال، نهائية FINISHED، توقيت LOBBY الفارغ، ومنع مالك منتهٍ من حذف قفل خلفه. أُزيلت الحاوية.
- خادم الوقت الحقيقي كاملًا: 379 ناجحًا و10 متخطّاة عبر 36 مجموعة ناجحة؛ lint وtypecheck وbuild ناجحة.
- الويب كاملًا: 3067 اختبارًا ناجحًا و106 متخطّاة عبر 461 ملفًا ناجحًا؛ فحص lint وtypecheck والبناء ناجحة. اختبارات DB الاختيارية المتخطاة في الحزمة العامة لا تحل محل حزمة PostgreSQL المخصصة الناجحة أعلاه.

فحص lint العام للويب انتهى دون أخطاء، مع تحذيرين خارج الملفات المعدلة في `public/games/sultan-farm/world.js` و`src/components/layout/site-shell.tsx`. لم يُعدّل هذان الملفان.

استدعاء الويب العام الأول مرر إعدادات مصادقة فارغة، فأظهر أخطاء Invalid URL. صُحح الاستدعاء بحذف المتغيرات من بيئة الاختبار بدل تمرير سلاسل فارغة؛ لم يُعدّل كود المنتج لمعالجة خطأ الاستدعاء.

## الفحص البصري المستقل

راجع المنفذ والمراجع الأساسي صورتَي `network-status-360x640.png` و`network-status-1920x1080.png`: تنبيها الاتصال والإرسال منفصلان بالعربية مع RTL ودون تجاوز أفقي. كشف فحص الكمبيوتر عمودًا ضيقًا للتنبيه؛ أُعيد استخدام تنسيق التنبيه الموجود ليمتد عبر الصف، دون CSS جديد.

هذه صور للحالة الجديدة ببيانات HTTP/media تجريبية. أدلة قبل وبعد الصقل السابق في `../tahaddi-live-focus/` محفوظة، وملفات CSS الثلاثة المعلقة بقيت مطابقة لنقطة الاستئناف. لا تُعد هذه الصور اعتمادًا للصوت أو الشبكة الإنتاجية.

## القيود والتراجع

- فقد إسقاط لوحة النتائج في Redis بالكامل يعيد شاشة كشف الإجابة الآمنة، ويحتاج المضيف ضغط التالي مجددًا. الموعد المشترك مع HTTP لا يكفي لاستعادة اسم المرحلة دون تغيير معناه.
- البث بعد حفظ DB بأفضل جهد. حدث `leaderboard:shown` القديم لا يحمل معرّف سؤال أو تسلسلًا؛ لا ضمان لترتيب جميع حزم لوحة النتائج قبل النهاية. حواجز النهاية والسؤال الأقدم لا تعني ضمان ترتيب الشبكة كاملة.
- انتهاء مدة قفل البلوت أثناء عملية طويلة وسياسة ابتلاع خطأ حفظ Redis القائمة مساران منفصلان. إصلاح انتهاء انتظار القفل لا يثبت سلامة عملية تتجاوز مدة ملكيته.
- لم يُنفّذ حمل إنتاجي أو تعطل SFU حقيقي أو اعتماد WebRTC/iOS. إعداد CI تحقق محليًا؛ لم يُشغّل GitHub في هذه المهمة.
- التراجع المحلي يعيد هذه الدفعة وحدها ويحفظ CSS السابق. قبل نشر مصرح، يلزم إصدار سابق متوافق وآمن؛ لا تُعاد ثغرة الهوية أو الكتابات غير الآمنة. لا توجد ترحيلات مدمرة أو آلية تعطيل طارئة مفترضة في الدفعة.

المصادر وإعادة الإنتاج والسجلات المحلية في `/workspace/scratch/tahaddi-operations-review/` و`/workspace/scratch/nasser-review/`. أدوات scratch ليست اعتماديات للتطبيق ولا ملفات منشورة.
