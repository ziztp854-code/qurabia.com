## الفريق والتنفيذ

شُغّل ستة وكلاء فرعيين فعليًا بالتوازي، بالإضافة إلى المنسق. فُصلت ملكية الملفات
داخل نسخة العمل القائمة؛ تولى المنسق الملفات المشتركة والدمج، وتولى QA وحده المتصفح
وخادم الاختبار على المنفذ 3417. التقط QA خط الأساس قبل تفعيل الإصلاحات.

## التغييرات

- استبدال effect قياس الأدوات بقياس محلي مجمّع في RAF واحد، مع تنظيف ResizeObserver
  وVisualViewport listeners. لا إعادة تركيب أو إعادة تصيير لجلسة الصوت عند تغيير المقاس.
- إزالة الحجز الدائم 210px لمنطقة الترحيب؛ يبقى الترحيب فوق المنصة دون تغطية الرأس
  أو الأدوات، ولا يعترض النقر إلا زر إغلاقه.
- توسيع الغرفة على الشاشات الكبيرة، وتوزيع المقاعد والدردشة والحضور حسب المساحة.
- حجز مساحة الأدوات المقاسة على الجوال؛ إبقاء حقل الرسالة والإرسال قابلين للتمرير
  والنقر والتركيز، ودعم ارتفاع وموضع visual viewport عند ظهور لوحة المفاتيح.
- إعادة تدفق الأدوات عند تكبير النص، وإزالة قيود عرض قديمة كانت تكسر التسميات،
  وجعل ارتفاع textarea يستوعب سطر النص الكبير.
- احتواء label قارئ الشاشة داخل composer؛ كان تموضعه المطلق يتسبب في 94px من
  التمرير الخارجي الزائد عند 320px. بقي label ووظيفته الدلالية محفوظين.
- إبقاء الهوية والأصول والألوان وقواعد الصوت والمسابقات وقاعدة البيانات كما هي.
  لم تُستخدم حيلة تصغير الواجهة بـ`transform: scale()`.

## الحدود والموافقات

لم يُختبر صوت فعلي بين جهازين، أو SFU حي، أو انقطاع شبكة حقيقي، أو جهاز محمول فعلي.
اختبارات media/reconnect المحلية ومراجعة ثبات lifecycle لا تعني قياس أداء الصوت على الأجهزة.
تجاوزت المجموعة الشاملة اختبارات تتطلب تكاملات غير متاحة؛ لا نعتبرها ناجحة.

لم يُنفّذ Push أو نشر على Vercel أو Render أو إنتاج، ولا تعديل مخطط قاعدة البيانات
أو migrations، ولا تغيير منطق الصوت أو المسابقات. تغييرات العمل المحلية معروضة للمراجعة
ولا تحتاج موافقة إضافية؛ أي Push أو نشر لاحق يتطلب موافقة المستخدم.
