## خريطة الرموز المحدودة

- إنشاء: `RoomEditor.save → RoomsScreen.onSave → useRooms.create/startMembership → createRoomsApi.create → POST rooms`.
- إنهاء/خروج مضيف: `NativeApp.runExit → executeRoomExit → voice.leave` محليًا، ثم `rooms.end/endRoom → POST close → inactive/empty confirmation → auth.signOut`.
- `NativeVoiceSession.leave` يوقف الصوت والخدمة محليًا ولا يغلق الغرفة على الخادم.
- اختبار Android ينشئ غرفتين عبر الواجهة ويطلب إغلاق الأولى بزر المضيف والثانية عند الخروج؛ oracle قاعدة البيانات يشترط inactive في العلمين، عضوية فارغة، وعدم leave/signout قبلclose.
- احتمال تزامن مصدرّي غير مُشغّل: إغلاق ملتزم مع فقد الرد وheartbeat يمسح العضوية قبل طلب التأكيد. قد يحجب الخروج رغم إغلاق الخادم؛ لا يفسر بقاء بث نشط، ولم يُعدّل هنا.
