# Motion Core

## Goal
Provide reusable motion primitives across Qurabia.

## Build
- motion tokens
- durations
- easing
- stagger
- reduced motion
- timeline helpers
- cleanup helpers

## Rule
Motion explains state changes.
CSS for simple micro-interactions.
GSAP for coordinated timelines and complex SVG/sequence work.

## Verification

Verify cleanup and reduced-motion behavior and confirm animations visualize state without controlling game timing.

## Integration scope

Follow the root `AGENTS.md` and `docs/qurabia-codex-guide.md`. Apply this guidance only to the requested work. Listed components, flows, and features are conditional guidance, not an instruction to create missing systems. Reuse existing tokens, contracts, and dependencies first.
