# SVG Motion

## Goal
Use lightweight vector motion for badges and game feedback.

## Suitable
- rank badges
- crown/shield/timer
- check/cross
- progress markers
- winner badge
- room status

## Techniques
- stroke-dasharray
- stroke-dashoffset
- masks
- clipPath
- transform
- opacity

Keep SVG assets reusable and accessible.
