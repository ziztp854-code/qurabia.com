# الحركة والأنيميشن

تكييف مستقل لـ Codex مستلهم من موضوع Emil Kowalski للحركة في دليل «تصاميم.pdf»، وليس المهارة الرسمية أو تنفيذًا آليًا لأوامرها. اتبع تعليمات المستخدم والمشروع أولًا.

1. افحص السطح الحالي والأحداث وحالة الواجهة والحركة والرموز الموجودة قبل التعديل. في تحدّي، التزم بـ `AGENTS.md` و`docs/qurabia-codex-guide.md` وقواعد `docs/visual-excellence.md`؛ لا تغيّر منطق اللعب أو مصدر البيانات من أجل الحركة.
2. اختر حركة توضّح انتقال الحالة أو التسلسل أو نتيجة فعل المستخدم. حدّد نقطة البداية والنهاية والمدة والمنحنى والتأخير بما يناسب المسافة والسياق؛ لا تجعل `linear` أو أي منحنى ممنوعًا مطلقًا عندما يناسب الغرض.
3. استخدم CSS للحركة البسيطة، وأعد استخدام مكتبات المشروع للتسلسلات المعقدة عند الحاجة. فضّل خصائص مناسبة للأداء مثل التحويل والشفافية، وتجنب إجبار التخطيط أو إعادة الرسم المكلفة دون قياس.
4. ادعم `prefers-reduced-motion` ببديل مفهوم، وتأكد من بقاء النص والحالة والوظيفة متاحة دون الحركة. تجنّب الومضات المؤذية والحركات المستمرة غير الضرورية؛ نظّف المؤقتات والمستمعات عند إزالتها.
5. عند طلب مراجعة، حدّد موضع الحركة، العيب، أثره، وطريقة إصلاحه. عند طلب نماذج متعددة، قارنها فقط إذا طلب المستخدم ذلك أو كانت المقارنة مفيدة بوضوح.
6. اختبر السلوك على مقاسات مناسبة، ومع الحركة المخففة ولوحة المفاتيح والنص الطويل حسب الحاجة. افحص النتيجة في المتصفح أو ملف الفيديو، واذكر حدود القياس بدل ادعاء أداء أو جودة لم تُختبر.
