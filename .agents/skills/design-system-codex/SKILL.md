# نظام التصميم والمراجعة

تكييف مستقل لـ Codex مستلهم من موضوع Impeccable في دليل «تصاميم.pdf». ليس إضافة Impeccable الرسمية ولا يوفّر أوامرها الخاصة بـ Claude Code. تعليمات المستخدم والمشروع أعلى أولوية.

1. افحص الهوية والرموز والمكونات والأنماط الفعلية ذات الصلة. في تحدّي، اتبع `AGENTS.md` و`design.md` و`docs/design-system.md` و`docs/visual-excellence.md`، وأعطِ التنفيذ الفعلي الأولوية عند اختلاف الوصف القديم.
2. طبّق النظام الموجود على المهمة المطلوبة: سلم الخطوط، التباين، المسافات، الحدود، الحالات والأزرار، مع الحفاظ على الهوية واللغة العربية واتجاه RTL. أعد استخدام المكونات والرموز قبل إنشاء بدائل.
3. عند طلب النقد، راجع التسلسل البصري والوضوح والسياق، وقدّم ملاحظات قابلة للتنفيذ مع أثرها. عند طلب التحسين، أصلح المشكلات ضمن النطاق بدل إعادة تصميم الموقع كاملًا.
4. عند التدقيق، افحص الاستجابة، التباين، لوحة المفاتيح، أسماء عناصر التحكم، الحالات الفارغة والخطأ، وقيود الحركة والأداء بحسب السطح. اختبر فعليًا على الهاتف والكمبيوتر عندما تتطلب سياسة المشروع ذلك؛ لا تعتبر البناء بديلًا عن الفحص البصري.
5. قبل التسليم، راجع القصّ والتداخل والأسماء الطويلة والتناسق والحالات التفاعلية، وشغّل الاختبارات الملائمة. اذكر الأدلة والفجوات؛ لا تدّعِ اجتياز تدقيق كامل عند نقص البيانات.
6. لا تنشئ `DESIGN.md` أو `PRODUCT.md` جديدين، ولا تغيّر الإطار أو تضف Tailwind أو مكتبات UI لمجرد الدليل. لا تنشر إلا وفق طلب المستخدم وقواعد المشروع.
