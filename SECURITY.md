# Security policy

## Supported code

Security fixes are applied to the latest code on the `main` branch.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository Security tab. Do not open a public issue or include credentials, room tokens, participant data, or exploit details in public discussions.

Include the affected route or event, a minimal reproduction, the expected impact, and any suggested mitigation. You should receive an initial acknowledgement within seven days.
